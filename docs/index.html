NixOS. No X11. No Wayland.

TetronOS, declared in one file.

tetron-nixos is the NixOS flavor of TetronOS: the same truecolor console, the same tetron-wm desktop made of text, the same private tetron mesh. The whole system comes from one flake, every change is a generation you can roll back, and every part also installs on the Linux you already have.

Early. The live ISO and the installer work, but there is no published release yet. Build the ISO yourself (below) or add single parts to your system today.

Live ISO

Build the live ISO.

A live system for USB or a VM, about 765 MB: it boots into the tetron-wm desktop. The same image carries the installer, so it can put TetronOS on a disk. Prebuilt ISOs will be attached to releases of this repository.

nix build github:tetronos/tetron-nixos#iso
ls result/iso/

amd64, BIOS and UEFI. The live user is tetronos with password tetronos, logged in on tty1. Writing it to a stick and installing to disk: install guide.

Parts

Take only what you want.

Each part of the tetron suite is a Nix package and a NixOS module, built on stock nixpkgs: every dependency comes from cache.nixos.org, and only the suite own code compiles. Turning a module on changes nothing else on the machine; a check in this repository proves it.

$nix profile install github:tetronos/tetron-nixos#tetron-tui

Any Linux with Nix, no NixOS needed. A signed binary cache saves compiling. All the steps: install guide.

Flavors

Two flavors, one suite.

TetronOS comes on two bases. The desktop, the mesh and the apps are the same; the packaging is not.

Status

Where it stands.

  • Done: live ISO that boots on BIOS and UEFI; installer (tetron-nixos-install, reads one install.json, partitions with disko); the five parts as packages and modules; a signed binary cache.
  • Next: an installer with a terminal UI, disk encryption and swap options, an offline closure in the ISO, and published ISO releases.
  • Versions: the suite moves in step on 0.15.x, the same as the Debian flavor.
