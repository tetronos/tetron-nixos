Install guide

tetron-nixos, step by step.

Pick the row that fits: one part on any Linux with Nix, some parts on your NixOS, the whole system as an ISO, or the ISO installed to disk. You need Nix with flakes enabled (experimental-features = nix-command flakes), which NixOS and the Determinate installer set up for you.

1. any Linux2. NixOS modules3. binary cache4. live ISO5. install to disk

1

Any Linux with Nix.

x86_64 and aarch64. Packages: tetron, tetron-tui, tetron-wm, casttui, kmscon. macOS: use the release binaries of each project.

nix run github:tetronos/tetron-nixos#casttui          # try it, nothing installed
nix profile install github:tetronos/tetron-nixos#tetron-tui
nix profile upgrade tetron-tui                        # later

The tetron daemon needs a system service. On NixOS use the module below. Elsewhere run sudo $(command -v tetron) install; the unit points at your profile link (~/.nix-profile/bin/tetron), so it survives nix profile upgrade. Needs tetron v0.15.7 or later.

2

NixOS: enable only what you want.

Add the flake as an input and the modules you want. Nothing else on the machine changes.

{
  inputs.tetron-nixos.url = "github:tetronos/tetron-nixos";
  outputs = { nixpkgs, tetron-nixos, ... }: {
    nixosConfigurations.myhost = nixpkgs.lib.nixosSystem {
      system = "x86_64-linux";
      modules = [
        ./configuration.nix
        tetron-nixos.nixosModules.tetron
        tetron-nixos.nixosModules.tetron-tui
        {
          services.tetron = { enable = true; operator = "alice"; };
          programs.tetron-tui.enable = true;
        }
      ];
    };
  };
}
sudo nixos-rebuild switch --flake .#myhost
tetron --help
  • services.tetron runs the mesh daemon; operator is the user who manages it without sudo.
  • programs.tetron-wm installs the desktop; desktop.enable adds its fonts and tools.
  • services.tetron-console replaces the login on the virtual consoles with kmscon and tetron-wm on tty1. Use it on a machine without a display manager.
  • programs.casttui installs casttui; openFirewall opens the ports Chromecast needs (45000 to 47000).
  • tetron-nixos.nixosModules.default is the whole TetronOS system: all parts plus the no-GUI console base, sound, wifi firmware and branding. It is what the live ISO and the installer set up.

3

Binary cache.

The suite packages are built and signed in tetron-nixos-cache. Without it Nix compiles them, which takes a while. Add it to /etc/nix/nix.conf and restart nix-daemon, or to nix.settings on NixOS:

extra-substituters = https://github.com/tetronos/tetron-nixos-cache/releases/download/cache
extra-trusted-public-keys = tetron-nixos-cache-1:VZnNn/Hb0ytcL354uHPmQeZA0CZheIIHUgjBVrghLUI=

On NixOS: nix.settings.extra-substituters = [ "..." ]; nix.settings.extra-trusted-public-keys = [ "..." ]; with the same two values.

4

The live ISO.

Build it on any machine with Nix (x86_64 Linux), then write it to a USB stick or boot it in a VM. It runs from RAM; nothing on the machine changes until you install.

nix build github:tetronos/tetron-nixos#iso
sha256sum result/iso/*.iso

Write it to USB

lsblk        # find the stick, e.g. /dev/sdX
sudo dd if=result/iso/tetronos-nixos-*.iso \
  of=/dev/sdX bs=4M status=progress conv=fsync

Or try it in a VM

qemu-system-x86_64 -enable-kvm -m 4G -smp 2 \
  -cdrom result/iso/tetronos-nixos-*.iso

Everything on the USB stick is erased. Ventoy works too. BIOS and UEFI. Log in as tetronos, password tetronos; tetron-wm starts on tty1.

5

Install to disk.

From the live system, tetron-nixos-install reads one install.json, writes a host flake, partitions the disk with disko and runs nixos-install. It refuses the disk the live system runs from. Name the disk by id so you hit the right one: ls -l /dev/disk/by-id.

{
  "disk": "/dev/disk/by-id/nvme-EXAMPLE_MODEL_SERIAL",
  "hostname": "mybox",
  "user": { "name": "alice", "hashedPassword": "..." },
  "ssh_at_boot": false,
  "wifi_firmware": []
}
mkpasswd -m sha-512          # paste the output as hashedPassword
sudo tetron-nixos-install install.json

Everything on the target disk is erased. The host flake stays on the machine in /etc/tetronos-config: change it, then sudo nixos-rebuild switch --flake /etc/tetronos-config#mybox. A terminal UI for the installer is planned.
